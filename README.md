# Ikamva Happy Feet — Website Project (Part 1 to Part 3)

## Overview
Ikamva Happy Feet is a non-profit project to assist rapid identification of individuals in emergencies by connecting hospitals, forensic teams and families.

## Folder structure
(see project root)

## How to run locally
1. Clone/download the folder to your machine.
2. Open index.html in a browser (or use Live Server in VS Code).
3. Ensure css/style.css and js/script.js are in their folders.
